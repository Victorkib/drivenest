# Routes

Pages live in this folder. TanStack Start maps each `.tsx` file to a URL.

| File         | URL                           |
| ------------ | ----------------------------- |
| `index.tsx`  | `/`                           |
| `__root.tsx` | App shell (keep `<Outlet />`) |

`src/routeTree.gen.ts` is produced by the router plugin. Leave it generated.
